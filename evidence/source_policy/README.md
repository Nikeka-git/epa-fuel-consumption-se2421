# Проверка источника 9 октября 2026 года

Сохранены фактические HTML-ответы документации API и официальной страницы Privacy/Security. URL, время UTC, HTTP status и SHA-256 находятся в manifest.json.

[Официальная страница](https://www.fueleconomy.gov/feg/ORNL-disclaimer.htm) разрешает некоммерческое научное и образовательное использование и распространение документов сайта. Фотографии автомобилей регулируются отдельно; проект собирает числовые и текстовые catalogue records через документированный API, без фотографий и пользовательских MPG записей.

Автоматическая попытка получить robots.txt завершилась закрытием соединения сервером; содержание robots.txt в этой сессии не подтверждено. Пользователь ранее сообщил о выполненной проверке. Не выдавать эту неудачную загрузку за проверенный robots snapshot. Первоначально предположенный URL copyright дал 404; правильный Privacy/Security URL обнаружен в footer документации и сохранен успешно.

Для сборщика выбраны один worker, интервал не менее секунды, ограниченные повторы и соблюдение Retry-After. Это настройка проекта, а не утверждение об опубликованном rate limit.
