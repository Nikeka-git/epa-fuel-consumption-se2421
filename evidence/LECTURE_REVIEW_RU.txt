Фиксированные стартовые настройки (НАШЕ решение, не указание лекций)

DummyRegressor(strategy='median'): соответствует primary MAE, медиана заново fit в каждом train fold. Lecture3 p40 объясняет median; выбор dummy и MAE исходит из rubric и вопроса проекта.
LinearRegression(fit_intercept=True): простая интерпретируемая линейная связь нескольких specs с расходом. Numeric median imputation; optional StandardScaler для численной устойчивости; categorical constant imputation и OneHotEncoder(handle_unknown='ignore', drop='first') для отсутствия dummy-variable collinearity с intercept. Не объявлять коэффициенты причинными эффектами; корреляция displacement/cylinders и категории осложняет interpretation. Не использовать model/baseModel/ID в X.
KNeighborsRegressor(n_neighbors=15, weights='uniform', p=2): усреднение по 15 соседям снижает чувствительность к единичной похожей комплектации. Число 15 предварительное, не «оптимальное» и не извлечено из лекции; оно должно быть < размера каждого fold-training. Numeric median imputation + StandardScaler обязательны для meaningful distance; categorical constant imputation + полный OneHotEncoder(handle_unknown='ignore', drop=None). Оставить равные веса для прямого соответствия описанному averaging. Расстояние по mixed numeric/one-hot данным и неизвестные категории — конкретные ограничения. Не использовать LabelEncoder для упорядочивания make/drive/class.
DecisionTreeRegressor(criterion='squared_error', max_depth=6, min_samples_leaf=5, random_state=42): ограничить рост дерева, получить nonlinear splits/interactions. Лекция p15 прямо обсуждает max depth и minimum samples как stopping criteria, но выбранные числа принадлежат проекту. Numeric median imputation + categorical constant imputation/one-hot; scaling для дерева не обязателен. Gini/entropy из классификационных слайдов не являются criterion для нашего regression tree; squared_error соответствует leaf mean. Одинаковые исходные features и IDs для всех подходов, preprocessing может быть обоснованно model-specific.

Для Midterm достаточно заранее зафиксированных осмысленных настроек и одинакового 5-fold group CV; большой search не требуется. Если пробовать маленькую sensitivity grid, явно отделить selection CV от независимой performance evaluation: например k={5,15,30}, tree depth={4,6,10} и leaf={5,10}, без test feedback. Это дополнительная нагрузка и не нужно для закрытия минимального rubric.

Метрики и важное отличие от формулы лекции

Primary по user request — MAE в L/100 km, объясняется средним модулем отклонения от EPA estimate. Это не конфликтует с обучением OLS на squared loss: training objective и evaluation metric не обязаны совпадать. Secondary RMSE на той же шкале связывает анализ с квадратичными ошибками и сильнее подчёркивает крупные промахи; R² дополнительный относительный показатель, не accuracy %.
Lecture3 PDF p18 минимизирует сумму квадратов residuals. P26 «Estimation of variance» содержит MSE=sum(r_i^2)/(n−2) для НЕСМЕЩЁННОЙ ОЦЕНКИ ДИСПЕРСИИ ОШИБКИ В SIMPLE LINEAR REGRESSION. Эту формулу нельзя копировать как test MSE/RMSE проекта: predictive MSE на m held-out observations = sum((y−pred)^2)/m. RMSE = sqrt этой predictive MSE. Для multivariate regression n−2 также не является общим числом степеней свободы. MAE = sum(abs(y−pred))/m.
P26 использует residual r=y_true−y_pred. Можно принять именно эту конвенцию для согласованности с лекцией: positive residual = модель занижает расход, negative = завышает. Предыдущая проектная заметка использовала противоположную конвенцию pred−true; математически обе допустимы, но нельзя смешивать. В финальном плане, коде и графиках выбрать одну и явно подписать. MAE/RMSE от знака не зависят.
MAE, RMSE и R² как обязательный набор эти лекции не задают; их выбор относится к задаче и rubric. Ошибочно приписывать им заранее определённый порог «хорошей» метрики. Требования split/pipeline/CV уже заданы rubric и продолжают действовать, даже если демонстрационный код лекции fit всей таблицы без holdout.
